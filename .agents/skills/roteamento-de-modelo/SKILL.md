# roteamento-de-modelo

Use Settings.routes e backend.integrations.llm. Configure endpoint OpenAI-compatible para Ollama ou OmniRoute.
Prefira scripts para Diretor operacional, Caçador e Editor. Escritor e Avaliador recebem contextos separados.
Reserve orçamento conservador antes da chamada. Falhas não devolvem a reserva; fallback não remove limites.
Nenhum nome de modelo é obrigatório. Configure custo real por milhão de tokens para estimativas úteis.
